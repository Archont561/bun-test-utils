# Audits

Point-in-time reviews of the tree: what was examined, what was found, ranked, and
what was done about it. An audit is a **record of a moment**, not a living document —
it is dated, and it is never rewritten once filed. Follow-ups it recommends become
Backlog tasks, not edits to the audit.

| Date | Audit | Scope |
|------|-------|-------|
| 2026-10-11 | [Docs site audit](./2026-10-11-docs-site-refactor.md) | `apps/docs`: information architecture, samples, badges, freshness signals, and snippet verification |
| 2026-10-06 | [Repo-wide refactor audit](./2026-10-06-repo-wide-refactor.md) | `packages/*/src`, `apps/*/src`, package scripts, TypeScript configuration, test layout |

File a new one as `YYYY-MM-DD-<topic>.md` and add a row above.
